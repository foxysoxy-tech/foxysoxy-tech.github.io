Einstellungen

Die Suche funktioniert ohne Konto über freie Suchdienste. Nur falls die mal ausfallen, kannst du hier optional einen eigenen YouTube-Schlüssel von Google eintragen:

  1. console.cloud.google.com öffnen, mit Google anmelden
  2. Oben „Projekt auswählen“ → „Neues Projekt“ → Erstellen
  3. „APIs & Dienste“ → „Bibliothek“ → „YouTube Data API v3“ → Aktivieren
  4. „Anmeldedaten“ → „Anmeldedaten erstellen“ → „API-Schlüssel“
  5. Schlüssel kopieren und hier einfügen

Feld leer lassen = Suche ohne Konto. Der Schlüssel bleibt nur auf diesem Handy.
